CellProfiler Flatpak Repository


Installation

To add this repository to your Flatpak setup, run the following command:

flatpak remote-add --if-not-exists cp-42x-dev https://gnodar01.github.io/cp-42x-dev/index.flatpakrepo

Alternatively, download the repo file and add it manually:

flatpak remote-add --if-not-exists cp-42x-dev ./index.flatpakrepo

Then, to install CellProfiler:

flatpak install org.cellprofiler.CellProfiler
